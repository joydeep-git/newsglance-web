## Overview

`newsglance-web` is the client-side application for NewsGlance. It consumes the `newsglance-api` backend to deliver a real-time news reading experience with AI-powered features: article summarization via Google Gemini and audio playback via AWS Polly TTS — all wrapped in a clean, responsive UI.

**Highlights:**
- **Infinite scroll** news feeds — homepage, category, country, and search
- **OTP-gated authentication** with email/password and Google OAuth2
- **AI article summaries** and **audio playback** with a custom audio player
- **Bookmark management** — save and revisit articles
- **Cashfree premium checkout** with payment status flow
- **Dark/Light mode** with `next-themes`
- Protected route group with session-aware layout wrapper
- **Vercel Analytics + Speed Insights** for performance monitoring

## Routing

### Open Routes (no auth required)

| Path | Page |
|---|---|
| `/` | Homepage — switches between homepage feed, category, country, and search based on query params |
| `/?category=technology` | Category news feed |
| `/?country=IN` | Country news feed |
| `/?search=elections` | Search results |
| `/article/<guardian-article-id>` | Full article detail with AI summary + audio |
| `/pricing` | Premium membership plans |
| `/contact` | Contact form |
| `/weather` | Weather page |
| `/payment-status` | Post-Cashfree payment result |

### Protected Routes (auth required)

| Path | Page |
|---|---|
| `/profile` | User profile — avatar, info |
| `/saved-news` | Bookmarked articles |
| `/settings` | Account settings — update profile, change password, delete account |

## Key Features

### Infinite Scroll News Feeds
All news feeds (homepage, category, country, search) use TanStack `useInfiniteQuery` with a 30-minute stale time. Pages are fetched on scroll, backed by a Redis-cached API.

### OTP Authentication
Every auth action (register, login, forgot password, delete account) requires a 6-digit OTP emailed to the user. The `input-otp` component provides a native OTP input experience.

### Google OAuth2
Single-click sign-in via `@react-oauth/google`. The ID token is exchanged with the backend, which creates or logs in the user automatically.

### AI Summarization
One click on any article triggers a Gemini-generated summary via `GET /api/news/summary/:newsId`. Results are cached server-side in PostgreSQL — repeat fetches are instant. Costs 1 daily credit for free users.

### Audio Player
A custom-built `<AudioPlayer />` component plays AWS Polly-generated MP3 audio. On first play, the audio is generated and uploaded to S3; subsequent plays stream from the cached URL.

### Bookmarks
Bookmark state is managed with React Query mutations. `useCheckBookmark`, `useSaveBookmark`, and `useDeleteBookmark` hooks keep the UI in sync with the API.

### Premium Checkout
The pricing page triggers `GET /api/payment/create` to create a Cashfree order, then mounts the Cashfree JS SDK checkout. After redirect, the `/payment-status` page verifies the order with the backend and shows a confetti celebration on success.

## Getting Started

### Prerequisites

- Node.js 20+
- npm

### Environment Variables

```env
NODE_ENV=development

# Google OAuth2
NEXT_PUBLIC_GOOGLE_CLIENT_ID=your_google_client_id


# Development:
NEXT_PUBLIC_BACKEND_URL=http://localhost:5000/api


# Production (via AWS CloudFront):
# NEXT_PUBLIC_BACKEND_URL=https://d3g4hp7x5o3v7g.cloudfront.net/api
```

---

### Local Development

```bash
npm install

npm run dev
```

App available at **`http://localhost:3000`**

---

### Production Build

```bash
npm run build

npm run start
```
